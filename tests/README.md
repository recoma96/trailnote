# 고도 프로파일 테스트

프로젝트와 CI에서 사용하는 Node.js 26에서 `npm test`로 실행합니다.
추가 테스트 패키지 없이 `node:test`로 실제 `src/app/lib/utils.ts`를 불러옵니다.
테스트는 TypeScript(`.test.mts`)로 작성하며, `npm run typecheck`에서 테스트 코드도 검사합니다.

`fixtures/juwangsan-joobong.json`은 `.traildata/juwangsan-joobong.json` 전체를 복사한 테스트 리소스입니다.
`.traildata`는 Git에서 제외되므로 CI는 이 고정된 복사본을 사용합니다. 외부 API나 이미지 요청은 하지 않습니다.
원본 데이터 변경을 테스트에 반영하려면 검토 후 fixture를 명시적으로 갱신하세요.

- 단위 테스트: 빈 배열, 한 점, 고도만 다른 좌표, 알려진 구면 거리, 누적 소수점 거리, 날짜 변경선, 원본 보존.
- 실제 데이터 테스트: 5개 구간의 마지막 누적 거리와 각 `segment.distance`의 절대 오차가 **0.1km 이하**인지 확인.
- 전체 코스 테스트: 825개 점의 고도·순서 보존 및 구간을 넘어 누적 거리가 감소하지 않는지 확인.

기록 거리는 첫 구간 0.6km, 두 번째 구간 1.8km로 수정된 데이터를 사용합니다.
기록 거리 비교는 데이터 일관성 검사이며 수학적 정확성은 단위 테스트로 별도 확인합니다.
전체 좌표를 연결하면 구간 사이의 거리도 포함되므로 구간별 계산 거리 합과 반드시 같지는 않습니다.
